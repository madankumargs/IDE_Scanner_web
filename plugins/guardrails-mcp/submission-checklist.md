# GuardRails MCP directory checklist

- [ ] Verify the GuardRails developer or business identity in the OpenAI Platform.
- [ ] Confirm `https://abscissa.dev/api/mcp` passes `initialize`, `tools/list`, and each tool-call workflow.
- [ ] Create a ZIP containing this directory, including `.codex-plugin/plugin.json`, `.mcp.json`, `mcp.json`, and `assets/logo.png`.
- [ ] Upload the ZIP in Plugins with the remote MCP server.
- [ ] Review MCP scan findings and run a rescan after any metadata update.
- [ ] Submit for review, choose supported countries, then publish.
- [ ] Request indexing for `https://abscissa.dev/docs/mcp` in the site search-console property.
